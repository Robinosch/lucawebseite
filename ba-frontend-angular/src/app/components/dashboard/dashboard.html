🔒 BFF-Pattern (Backend-for-Frontend)

  • ✅ Keine Token im Frontend
  • ✅ HTTP-only Cookies für Session
  • ✅ Backend validiert alle Tokens
  • ✅ CSRF-Schutz aktiviert
  • ✅ XSS-sicher: Kein Token-Storage

Sicherheitsvorteil: Tokens sind für JavaScript nicht zugreifbar.
